# YT-Tools for Blender v1.8 Release Note

## ✨ New Features Overview

### 🔹 New Empty Mesh, Teapot
New Empty Mesh adds a new, empty mesh object.<br>
Teapot adds a primitive teapot shape. In Edit Mode, it adds a teapot to the currently selected mesh. In Object Mode, it adds a new mesh object and adds a teapot to it.

### 🔹 Clipboard Update
**Clipboard** now supports freestyle face and bevel edge weighting in the clipboard. The **ModoClipboard kit** is available from [Gumroad](https://tazaki.gumroad.com/) or [Github](https://github.com/tazee/ModoClipboard/releases) download site. Now **LightWave Clipboard** is available on [Gumroad](https://tazaki.gumroad.com/).

### 🔹 Statistics Update
**Statistics** now supports freestyle face and bevel edge weighting.
